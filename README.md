## AGILE - QUẢN LÝ DỰ ÁN NỘI BỘ

Đây là hệ thống dự trên việc phát triển ứng dụng quản lý công việc nhằm đảm bảo hiệu quả công việc và tốc độ làm việc trong dự án.
Đây là dự án Outsource. Có thể lấy về và chỉnh sửa thêm để phù hợp với dự án nội bộ.

### 🔹 Các chức năng chính
- **Dashboard:** Tổng hợp các dự án, lịch sử chỉnh sửa cùng các chỉnh số
- **Giao diện quản lý dự án:** Sử dụng các phương pháp phát triển linh hoạt nhằm tạo ra ứng dụng quản lý công việc nội bộ
- **Dữ liệu lưu trữ:** Sử dụng MongoDB để lưu trữ dữ liệu lịch sử cùng quản lý nhân viên làm việc
- **Burndown Chart cùng các chỉ số:** Nghiên cứu hiệu quả làm việc và hướng giải quết nếu US bị chững lại

---

## ⚙️ Tải về

1. Tải VS Code về.
2. Dùng Git để tải repository:
   ```bash
   https://github.com/KenTruong1610/Agile_BI.git
   ```
3. Vào terminal và viết 
   ```bash
   cd "C:\Agile_BI"
   npm run build
   npm run preview -- --host [mạng] --port [số]
   ```
   để khởi động
4. Vào localhost:[số] để vào hệ thống

## Dữ liệu
Danh sách các bài báo được lưu vào MongoDB và có thể tải thông qua Json/CSV (Các bạn có thể tự thêm vào). Dữ liệu được xử lý và ghi trong cơ sở dữ liệu. Báo cáo truy vấn dữ liệu theo thời gian.
